## 3. 설명해야 하는 것

### 3-1. 질문 정의 (A1)

- Q1 언제부터 · 얼마나 빠르게 커졌나 — 그림 1 · 2
- Q2 급등은 언제, 기능 발표 · 쇼핑 시즌과 겹치나 — 그림 3 (해석 필요)
- Q3 관심의 내용이 바뀌었나(일반어 → 구체 서비스 · 개념) — 그림 4
- Q4 2026년 7월 급락은 관심 감소인가, 측정 변화인가 — 그림 5 · 6 (해석 필요)
- Q5 한국도 같은 흐름인가, 시차는 — 그림 7

### 3-2. 결측치 · 이상치 기준 (A2)

- 결측치
  - 날짜 누락 · NaN = 0건(달력과 대조)
  - 진행 중인 마지막 주(`isPartial=True`) = 하루~이틀치라 낮게 보임 → **제거**(262 → 261주)
  - 0 = 결측이 아니라 "검색량이 임계값 미만" → **유지**. 단, 변화율 분모가 5 미만이면 계산 안 함(0~4 는 반올림 오차가 큼)
- 이상치
  - 급등 = 분석 대상(사건) → **지우지 않고 표시**: 직전 8주 중앙값 대비 로버스트 z ≥ 2.5 → 10주
  - 7월 급락 = 한 점이 아니라 수준 이동(구조 단절) → **보정 · 삭제 안 함**, 앞뒤 구간을 나눠 분석(이동평균도 단절 앞뒤 따로 계산)
  - 원칙: 지우기 전에 "사건인가, 오류인가" 를 먼저 가린다

### 3-3. 관찰 vs 해석 (A3)

- 관찰 = 그래프 · 표에서 누구나 같은 값을 읽는 것 — "2026-07-12 주에 AI 관련 검색어 6개가 −67~−80%"
- 해석 = 관찰을 설명하는 추측 + 근거 + 반례 — "구글 측정 변화일 가능성이 크다(근거: 위키백과 +25%, 대형 검색어 그대로 / 반례: 공식 공지 없음)"
- 리포트는 그림마다 **관찰 / 해석(가설)** 을, 인사이트마다 **관찰(Fact) · 원인(Why) · 행동(Action)** 을 나눠 적었다

### 3-4. 트렌드 · 계절성 · 노이즈 (B1)

- 트렌드 = 장기 방향: 2023~24 완만 → 2025 급증 → 2026 상반기 둔화
- 계절성 = 해마다 같은 시기 반복: 11월(블랙프라이데이) +23%, 주말이 평일보다 3~10% 높음
- 노이즈 = 나머지 출렁임: 주 단위 들쭉날쭉 · 표본 오차(같은 검색어를 두 번 받아 상관 0.997)
- STL 분해 결과: 'AI shopping' 변동의 97% 가 추세(계절 1%) ↔ 대조 'online shopping' 은 추세 56% · 계절 33% → AI 쇼핑은 아직 성장 단계라 계절성이 추세에 묻힘

### 3-5. 이동평균 · 변화율 — 왜 / 어떻게 (B2)

- 이동평균: 주간 노이즈를 걸러 추세를 본다
  - 4주 = 한 달, 13주 = 한 분기
  - 그림은 가운데 정렬(시점이 밀리지 않음), 대시보드는 직전 N주 평균(후행 — 지금 시점까지만 사용)
  - 7월 단절을 넘지 않게 앞뒤를 따로 계산 — 넘으면 단절 전 값에 단절 후 낮은 값이 섞여 추세가 왜곡됨(실제로 '정체' 착시를 만들었다가 바로잡음)
- 변화율: 급등과 성장 속도를 숫자로
  - 전주 대비 → 급등 탐지 · 전분기 대비 → 성장 둔화(+203% → +8%) · 1년 전 같은 구간 대비 → 계절 기준선
  - 수준이 크게 다른 시기는 로그 기울기로: 2025 주 +6.0%(12주마다 2배) vs 2026 상반기 주 +0.9%
- 집계 단위 근거: 5년 흐름은 주간으로만 받을 수 있고, 일간 요일 차이가 작아(−4~+6%) 주로 묶어도 잃는 정보가 적음
- 스케일 근거: 선형 눈금에서는 2023~24 값(1~5)이 바닥에 깔림 → 로그 눈금 패널 추가

### 3-6. AI 활용과 검증 (C1)

- 맡긴 일: 데이터 출처 탐색 · 수집/분석/대시보드 코드 · 그림 · 초안 문장
- 검증 방법
  - 원자료로 수치 재계산(2025 Q3 평균 42.15 · 사건 전후 27.25 → 49.5 · 블랙프라이데이 8 ÷ 5.25 = 1.52)
  - 사건 날짜는 웹 검색으로 회사 발표 · 주요 보도와 대조(링크를 리포트 표에 남김)
  - 가설은 대조군 · 위키백과 · 일간 데이터로 근거/반례 확인
  - 그림을 직접 열어 겹침 · 잘림 수정 · 지우고 다시 만들어 결과 일치 확인
- AI 결과를 고친 사례(대표 3개)
  - "2026 상반기 정체(주 +0.1%)" → 이동평균이 단절 후 값을 섞은 착시 → "둔화(주 +0.9%)"
  - 급락 그림 제목 "AI 검색어에만 급락" → 비AI 소량 검색어도 떨어진 것 확인 → 정정
  - 예측의 "단절 구간 최선 = 계절 naive" → 작년 수준과 우연히 비슷했을 뿐임을 명시

### 3-7. 최종 판단의 근거 — 7월 급락 (C2)

- H1 구글 집계 변화 — 근거: 미국 · 한국이 같은 주에 동시 하락 · 소량 검색어일수록 크게 하락 · 대형 검색어 그대로 · 위키백과는 증가
- H2 검색 행동 이동(검색창 → AI 챗봇) — 반례: 행동 이동은 점진적이어야 하는데 열흘 만에 두 나라 동시
- H3 실제 관심 감소 — 반례: 위키백과 'Agentic commerce' 조회 +25%, 9월 말 최고치
- 판단: H1 이 가장 잘 맞지만 공식 공지가 없어 **확정하지 않음** → 7월 앞뒤 값을 직접 비교하지 않는 것으로 대응

### 3-8. 보너스 — 분해 · 예측 · 대시보드

- 분해(그림 8): 주기 3.5번뿐이라 계절 패턴을 고정하고 추세 창 53주 — 7월 +12% 는 2025년 한 번의 급등이 계절로 흡수된 것(한계)

## 5. 예상 꼬리 질문

- 왜 Google Trends? — 'AI 쇼핑 관심' 에 직결되는 무료 · 키 없는 지표. 한계는 상대 지수라 실제 검색 횟수가 아님
- 왜 미국이 주 데이터? — 한국 구글 검색은 양이 적어 261주 중 193주가 0, 미국은 신호가 충분. 한국은 비교용
- 0 을 왜 지우지 않았나? — 결측이 아니라 "아주 낮음" 이라는 정보. 지우면 2023년 이전 관심이 없었다는 사실이 사라짐
- 급락 구간을 왜 보정하지 않았나? — 원인을 모르는 채로 보정하면 가정을 데이터에 덮어쓰게 됨. 구간을 나눠 다룸
- 사건과 급등이 겹치면 원인인가? — 아니다, 시점 일치일 뿐. 사건 창 겹침(⑧ · ⑨)과 시즌 겹침(⑩ · 블프)은 분리 불가
- 'price comparison' 이 20배 뛴 건? — 'AI shopping' 과 함께 뛰고 함께 꺼짐 → 자동화된 질의 같은 같은 성분이 섞였을 가능성(가설)
- 데이터를 다시 받으면? — 표본이 달라 값이 조금 바뀜 → 받은 원본을 커밋해 분석 기준으로 고정
- 노트북 대신 스크립트인 이유? — 지우고 다시 실행했을 때 결과가 바이트 단위로 같은지 `git status` 로 바로 확인 가능
- 이동평균 그림과 대시보드 값이 조금 다른 이유? — 그림은 가운데 정렬, 대시보드는 후행 평균
