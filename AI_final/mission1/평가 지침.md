# 평가 지침 — AI 쇼핑 관심도 시계열 분석

> 과제의 두 축 = **시계열 데이터를 정제 · 분석 · 시각화해 재현 가능하게 남기기** + **관찰과 해석을 구분한 인사이트 리포트**. 아래 6단계를 순서대로 따라 하면 모든 요구사항이 확인됨

- 저장소: https://github.com/sujileelea/Codyssey/tree/develop/AI_final/mission1 · 리포트: `REPORT.md` · 실행 방법: `README.md` · 상세 기록: `실행 로그.md`

---

## 1. 저장소 · 구조

```bash
git clone -b develop https://github.com/sujileelea/Codyssey.git && cd Codyssey/AI_final/mission1
ls                        # REPORT.md README.md requirements.txt collect.py analysis.py build_dashboard.py data/ images/ outputs/ dashboard/
ls data/raw               # 수집 원본 CSV 7개(주 데이터 = trends_us_weekly.csv, 262행)
cat data/metadata.json    # 파일별 출처 · 검색어 · 기간 · 수집 시각
git log --oneline -- .    # 수집 → 분석 · 시각화 → 대시보드 → 리포트 순서의 커밋
```

## 2. 재현 — 그림 · 표 다시 만들기

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python analysis.py          # 데이터 품질 표 출력 → images/ 9장 · outputs/ 표 · key_numbers.json
python build_dashboard.py   # dashboard/index.html
```

- 기대: 첫 출력 "데이터 품질 점검" 표에서 주 데이터 261행 · 날짜 누락 0 · NaN 0 · 제거한 진행 중 주 2026-10-25
- `data/raw/` 가 이미 있어 네트워크 없이 재현됨 · 데이터를 새로 받으려면 `python collect.py --force`(값이 표본에 따라 조금 달라질 수 있음)
