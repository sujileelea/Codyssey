# 1. 미션 요약

> 일반 챗봇은 내 데이터를 모른다 — **시계열 데이터를 분석해 DB 에 저장하고, 그 요약을 AI 에 넣어 "내 상황을 아는 AI 비서"** 를 웹 서비스로 만든다

- 시계열 데이터 분석 → 요약 → Firestore 저장 → 요약을 시스템 프롬프트에 주입한 GPT 대화 → 대화 기록 저장 · 불러오기 → Render · Vercel 배포
- 이번 구현 = **AI 쇼핑 관심도 비서**: 미션1에서 분석한 미국 Google Trends 'AI shopping' 주간 지수 261개를 데이터로 쓰고, "이번 달은?", "가장 높았던 때는?", "작년 같은 시기와 비교하면?" 에 날짜 · 수치로 답한다

# 2. 과제 목표
> 수료 후 스스로 설명할 수 있다!

| 목표 | 이번 구현에서 |
| --- | --- |
| 시계열 분석 → 요약 → 서비스 활용 흐름 | 261개 → `analysis.summarize()`(기간 · 개수 · 기본 통계 · 단기/장기 추세 · 최근 값 · 월평균 · 메모 시점) → `/api/data/summary` · 채팅 주입 · 요약 패널이 같은 함수를 씀 |
| FastAPI 를 라우터 / 서비스로 분리한 기준 | 라우터 = HTTP 입출력, 서비스 = 규칙 · 계산 · 외부 호출, 저장소 = Firestore 쿼리 — 층마다 모르는 것을 정해 둠 |
| Pydantic 요청 검증의 이유와 방식 | 잘못된 값이 서비스 · DB 에 닿기 전에 422 로 거름(날짜 형식 · 범위 · 숫자 · 길이 · 모르는 필드), 사유는 필드별 한국어 |
| Firestore 저장 · CRUD | `data` · `conversations` 두 컬렉션, 날짜는 ISO 문자열로 저장해 정렬 · 범위 조회, 목록은 필드 선택으로 가볍게 |
| 컨텍스트 주입 원리 | 매 질문마다 요약을 새로 계산해 시스템 프롬프트 글로 넣음 → 모델은 그 숫자를 근거로 답하고, 데이터를 바꾸면 다음 답이 바뀜 |
| 배포 환경의 CORS · 환경 변수 · 키 관리 | 프론트(Vercel)와 API(Render)는 출처가 달라 CORS 허용 필요, 키는 코드가 아닌 환경 변수 · 저장소 밖 파일 |

# 5. 핵심 개념 정리

## 5-1. 컨텍스트 주입

| | 일반 챗봇 | 이번 서비스 |
| --- | --- | --- |
| 모델이 아는 것 | 학습한 일반 지식 | 일반 지식 + 매 요청마다 넣어 준 **내 데이터 요약** |
| 넣는 곳 | — | 시스템 프롬프트(대화의 전제 조건, 사용자 질문보다 앞) |
| 데이터가 바뀌면 | 모름 | 다음 질문부터 새 요약이 들어가 답이 바뀜 |
| 한계 | — | 요약에 없는 세부 값은 모름 → 보너스의 도구 호출로 보완 |

- 원자료 전체(261행)를 넣지 않고 요약을 넣는 이유: 토큰(비용 · 지연) 절약, 모델이 큰 표에서 숫자를 잘못 읽을 위험 감소
- 답변 규칙도 함께 넣는다 — 요약 수치만 근거로 · 날짜와 수치를 함께 · 관찰과 해석 구분 · '이번 달' 은 데이터 마지막 날짜 기준

## 5-2. FastAPI 구성 · Pydantic

- 라우터는 "어떤 URL 에 무엇을 받아 무엇을 돌려주나" 만, 서비스는 "무엇이 옳은가(규칙) · 어떻게 계산하나", 저장소는 "어디에 어떻게 저장하나" 만 안다 → 바꿀 때 한 층만 고치면 된다(예: DB 교체 시 저장소만)
- Pydantic 모델 = 요청 본문의 설계도. 형식이 틀리면 FastAPI 가 핸들러를 부르기 전에 422 를 돌려준다 → 서비스 코드는 검증된 값만 다룸, Swagger UI 에도 같은 설계도가 문서로 나옴

## 5-3. Firestore

| 개념 | 이번 구현 |
| --- | --- |
| 컬렉션 / 문서 | `data/{자동 ID}` · `conversations/{자동 ID}` |
| 정렬 · 범위 조회 | 날짜를 `"YYYY-MM-DD"` 문자열로 저장 → 사전순 = 시간순 |
| 중복 방지 | 추가 · 수정 전에 `where(date == …)` 로 확인 → 409 |
| 읽기 횟수 절약 | 전체 목록 60초 캐시(이 서버를 거친 쓰기는 즉시 무효화), 대화 목록은 필드 선택으로 messages 제외 |
| 보안 규칙 | 기본값(외부 접근 차단) — 브라우저는 DB 에 직접 닿지 않고 API 를 거침 |

## 5-4. 배포 환경의 CORS · 환경 변수 · 키

- **CORS**: 브라우저는 페이지 출처(Vercel)와 다른 출처(Render)로 보내는 요청에 대해 서버가 "이 출처는 허용" 이라고 답할 때만 응답을 넘겨준다 → `ALLOWED_ORIGINS` 에 프론트 주소만
- **환경 변수**: 같은 코드를 로컬 · 배포에서 다른 설정으로 돌리기 위해(주소 · 키 · 제한값)
- **키 관리**: 키가 저장소에 들어가면 공개 저장소에서 누구나 쓸 수 있다 → 코드에는 이름만, 값은 Render 대시보드 · 로컬 `.env`(커밋 제외) · 저장소 밖 키 파일
