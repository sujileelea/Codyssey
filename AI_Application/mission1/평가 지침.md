# 2. GitHub 저장소 · Git 명령 8종 (요구 2 · 4-Git · 7)

## 2-1. 저장소 받기

```bash
git clone https://github.com/sujileelea/prompt-manager.git      # clone
cd prompt-manager
```

| 확인 항목 | 명령 | 기대 결과 |
| --- | --- | --- |
| 코드 업로드 | `ls` | `main.py` `data.py` `README.md` `.gitignore` `LICENSE` |
| 커밋 10개 이상 | `git rev-list --count HEAD` | **15** |
| 기능 단위 커밋 메시지 | `git log --oneline` | `feat:` `chore:` `docs:` `merge:` 접두어, 변경 의도가 메시지에 있음 |
| 브랜치 생성·병합 기록 | `git log --oneline --graph` | `merge: feature/list 브랜치를 main에 병합` 커밋에서 `\|\` `\|/` 분기·합류 |
| 원격 연결 | `git remote -v` | `origin https://github.com/sujileelea/prompt-manager.git` |
| `.gitignore` | `cat .gitignore` | `__pycache__/` `*.pyc` `.venv/` `.vscode/` `.DS_Store` `exports/` `prompts.json` |
| README | `cat README.md` | 프로그램 이름·설명 · 실행 방법 · 기능 목록 · 카테고리 설명 |

## 2-2. Git 명령별 사용 근거

| 명령 | 근거 |
| --- | --- |
| `init` | 첫 커밋 `c4846d3 chore: 프로젝트 초기화` (저장소 시작) |
| `add` · `commit` | 커밋 15개 |
| `push` | 원격 `origin/main`이 로컬과 동일 — `git status -sb` → `## main...origin/main` |
| `checkout` · `merge` | 그래프의 분기·병합 (`bbbf8db` feature/list 커밋 → `add1101` 병합 커밋) |
| `clone` | 공개 샘플 `octocat/Hello-World` clone 기록 = `캡처/clone_샘플저장소.txt` · 평가자 본인의 clone(2-1) |
| `pull` | `da792f4 chore: MIT LICENSE 추가 (다른 clone에서 커밋 → pull 실습용)` — 별도 clone에서 push 후 원본 폴더에서 `git pull`로 받은 커밋 |

- 상세 기록: `실행 로그.md` §2·§3 · 증빙: `캡처/04_git_log_graph.png`

# 3. 프로그램 기능 (요구 4-프로그램)

```bash
python3 main.py
```

## 3-1. 실행·메뉴

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| (실행 직후) | 구역 나뉜 메뉴 `1~12`, `0 종료`, 헤더에 `등록 9개 · 즐겨찾기 2개` | 메뉴 출력 |
| `99` Enter | `'99'는 없는 번호입니다. 0~12 중에서 골라주세요.` → Enter → 메뉴 재출력 | 잘못된 번호 안내 · 메뉴 복귀 |
| (기능 하나 실행 후) | `[Enter] 메뉴로 돌아가기` → Enter → 메뉴 | 각 기능 후 메뉴 복귀 |
| `0` Enter | `프로그램을 종료합니다.` 후 종료 | 종료 |

## 3-2. 기본 프롬프트 데이터

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `2` | 프롬프트 **9개** 출력 (번호 · `[카테고리]` · 제목 · ⭐) | 3개 이상 사전 등록 |
| `cat data.py` (터미널) | `DEFAULT_PROMPTS = [ {"title", "content", "category", "favorite"} … ]` | 리스트+딕셔너리 · 4개 필드 |
| — | 출처: GenAI 미션1(페르소나·정보추출) · 멀티모달 미션2(이미지 2·영상 1) · 자동화 미션3(Gemini) · 팀 프로젝트(요약·인사이트·감성) | 이전 미션 프롬프트 |

## 3-3. 프롬프트 추가

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `1` → 제목에 Enter만 | `제목은(는) 비워둘 수 없습니다. 다시 입력해주세요.` | 빈 값 재입력 |
| 제목 `테스트` → 내용 `첫 줄` Enter `둘째 줄` Enter, 빈 줄 Enter | 카테고리 선택 화면 `1) 텍스트 생성 … 6) 기타 7) 직접 입력` | 제목·내용·카테고리 입력 |
| `9` | `목록에 있는 번호를 입력해주세요.` | 잘못된 선택 안내 |
| `1` | `'테스트' 프롬프트가 추가되었습니다! (총 10개)` | 리스트 저장 |
| `7` → 직접 입력 `연구` | 새 카테고리로 등록 | 직접 입력 |
| `2` | 10번 `[텍스트 생성] 테스트` — ⭐ 없음 | 즐겨찾기 기본값 False |
| 프로그램 종료 후 재실행 → `2` | 9개 (추가분 사라짐) | 실행 중에만 유지 |

## 3-4. 프롬프트 목록 (브랜치 작업 기능)

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `2` | 번호 · `[카테고리]` · 제목 · ⭐(1번·4번), `총 9개의 프롬프트` | 번호·제목·카테고리·즐겨찾기 표시 |
| (11번으로 전부 삭제 후) `2` | `등록된 프롬프트가 없습니다.` | 없으면 안내 |
| `git log --oneline --graph` | `feature/list` 분기 → `main` 병합 | 브랜치에서 작업 후 병합 |

## 3-5. 카테고리별 조회

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `3` | 카테고리 목록 `1) 텍스트 생성 … 6) 기타` | 카테고리 목록 표시 |
| `2` | `[이미지 생성] 카테고리 프롬프트:` 3번·4번, `총 2개` | 해당 카테고리만 출력 |
| (`기타` 삭제 후) `3` → `6` | `[기타] 카테고리에 등록된 프롬프트가 없습니다.` | 없으면 안내 |

## 3-6. 프롬프트 검색

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `4` → `뉴스` | 6·7·8·9번, `4개의 프롬프트를 찾았습니다.` | 제목 또는 내용 포함 검색 |
| `4` → `turquoise` | 3·4·5번 (내용에만 있는 영문, 대소문자 무시) | 내용 검색 |
| `4` → `없는말` | `'없는말'을(를) 포함한 프롬프트가 없습니다.` | 결과 없음 안내 |

## 3-7. 프롬프트 상세 보기

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `5` → `1` | 구분선 안에 제목 · 카테고리 · 즐겨찾기 ⭐ · 조회수 · 내용 전체(여러 줄) | 전체 내용 출력 |
| `5` → `99` | `잘못된 번호입니다. 1~9 사이의 번호를 입력해주세요.` | 잘못된 번호 안내 |

## 3-8. 즐겨찾기

| 입력 | 기대 결과 | 요구 |
| --- | --- | --- |
| `6` → `2` | `'공고 정보추출 (JSON 구조화)' 프롬프트를 즐겨찾기에 추가했습니다!` | 추가 |
| `7` | 1·2·4번만, `총 3개의 즐겨찾기` | 즐겨찾기만 모아 보기 |
| `6` → `2` | `… 즐겨찾기에서 해제했습니다!` → `7`에서 2번 사라짐 | 해제 |

# 6. 한 번에 확인하는 명령 모음

```bash
# 환경
python3 --version && git --version && git config --global --list | grep -E "user\.|defaultBranch"

# 저장소·이력
git clone https://github.com/sujileelea/prompt-manager.git && cd prompt-manager
git rev-list --count HEAD            # 15
git log --oneline --graph            # feature/list 분기·병합

# 코드 구조
grep -c "^def " main.py              # 27
grep -E "^import|^from" main.py data.py

# 프로그램 (자동 입력으로 전 기능 훑기: 목록→추가→검색→상세→즐겨찾기→목록→종료)
printf '2\n\n1\n테스트\n첫 줄\n둘째 줄\n\n1\n\n4\n뉴스\n\n5\n1\n\n6\n2\n\n7\n\n0\n' | python3 main.py
```
