VS Code 통합 터미널(`` Ctrl+` ``)에서

```bash
git config --global user.name && git config --global user.email && git config --global init.defaultBranch
```

- 기대: `Python 3.13.x` · `git version 2.x` · 이름 · 이메일 · `main`
- VS Code 확장 패널에 **Python** 설치, 왼쪽 하단 계정 아이콘에 **GitHub 사용자명**

## 4. 커밋 이력 · 브랜치 병합

```bash
git log --oneline --graph
```

- 기대: 커밋 **16개**(`feat:`·`chore:`·`docs:` 기능 단위 메시지), `feature/list` 분기(`|\`)와 `main` 병합(`|/`) 커밋 `merge: feature/list 브랜치를 main에 병합`
- 증빙 `캡처/04_git_log_graph.png`

## 5. Git 명령 8종 사용 근거

| 명령 | 근거 |
| --- | --- |
| `init` · `add` · `commit` · `push` | 첫 커밋 `chore: 프로젝트 초기화`부터 16개 커밋이 GitHub에 올라와 있음 |
| `checkout` · `merge` | 4단계 그래프의 분기·병합 |
| `clone` | 공개 샘플 `octocat/Hello-World` 확인 기록 `캡처/clone_샘플저장소.txt` + 3단계 |
| `pull` | 커밋 `chore: MIT LICENSE 추가 (다른 clone에서 커밋 → pull 실습용)` — 별도 clone에서 push한 것을 원본 폴더에서 `git pull`로 받음 |

## 6. 프로그램 실행 · 메뉴

```bash
python3 main.py
```

- 기대: 메뉴 `1~12`, `0 종료` 출력 → `99` 입력 시 `없는 번호입니다` 안내 후 메뉴 복귀 → `0`으로 종료
- 증빙 `캡처/02_실행_메뉴_목록.png`

## 7. 기본 데이터 · 목록 · 상세 · 즐겨찾기
