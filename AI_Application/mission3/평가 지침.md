## 1. 배포 URL 에서 페이지 이동 · 반응형

- 홈 → 상단 메뉴 **시연 · 프롬프트 매트릭스 · FAQ** 로 이동, 현재 페이지가 강조됨
- 브라우저 폭을 400px 정도로 줄이면 메뉴가 ☰ 버튼으로 바뀌고 시연 화면이 1열로 재배치됨 (개발자 도구 기기 모드로 확인)
- 오른쪽 위 🌙 버튼 → 다크 모드, 새로고침해도 유지 (보너스)
- 증빙 `캡처/데스크톱.png` · `캡처/모바일.png`

## 2. AI 기능 — 정상 입력

- 시연 페이지 → **행사 포스터** 샘플 버튼 → 매트릭스가 `public.notice.poster.event.formal` 로 맞춰짐 → **대체텍스트 생성**
- 기대: 3~10초 안에 결과 카드 — 대체텍스트(행사명·일시·장소), HTML 스니펫, 보충 설명, 이미지 안에 적힌 글 전문, 사용된 블록 칩, "실제로 보낸 프롬프트 보기"
- 같은 사진으로 분야를 **언론사**, 톤을 **친근** 으로 바꿔 다시 생성 → 문체·강조점이 달라지는 것을 비교
- 증빙 `캡처/AI동작.png`

## 3. AI 기능 — 실패 처리

| 조작 | 기대 |
| --- | --- |
| 사진 없이 생성 | 빨간 안내 "사진을 올려 주세요…" (요청 미발송) |
| `.txt` 등 이미지 아닌 파일 드롭 | "JPEG·PNG·WebP·GIF 이미지만 올릴 수 있습니다." |
| 짧은 시간에 여러 번 연속 생성 (무료 한도) | "지금 요청이 많습니다. 1분 뒤 다시 시도해 주세요. [RATE_LIMITED]" |
| 네트워크를 끊고 생성 | "네트워크 오류로 요청을 보내지 못했습니다" / 30초 뒤 지연 안내 |

## 4. 백엔드 · fetch 구조

```bash
curl -s https://aitag-demo-gamma.vercel.app/api/options | head -c 200      # GET — 매트릭스 선택지 JSON
curl -s -X POST https://aitag-demo-gamma.vercel.app/api/alt_text -H 'Content-Type: application/json' -d '{}'
# → {"error": "EMPTY_IMAGE", "message": "사진을 올려 주세요. …"}  (400)
```

- `api/options.py` `api/alt_text.py` = Vercel Serverless Functions(Python, `handler` 클래스) · `requirements.txt` 에 `requests`
- `js/demo.js` 에서 `fetch("/api/alt_text", {method: "POST", body: JSON})` → 응답을 `render()` 로 DOM 에 반영
