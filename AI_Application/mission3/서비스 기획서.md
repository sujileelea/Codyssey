# 서비스 기획서 — AITAG 시연

## 1. 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스명 | **AITAG 시연** — 사진 + 프롬프트 매트릭스 → 대체텍스트 |
| 한 줄 정의 | 사진을 올리고 이미지가 쓰이는 자리(분야·콘텐츠 유형·이미지 유형·카테고리·톤)를 고르면 AI 가 스크린리더용 대체텍스트를 써 주는 웹 데모 |
| 목적 | ① 대체텍스트의 "좋은 기준"이 쓰임새마다 다르다는 것을 체험하게 한다 ② 프롬프트를 조합 수만큼 쓰지 않고 축별 블록을 **합성**하는 방식(프롬프트 매트릭스)을 눈으로 보여 준다 ③ AI 대체텍스트 서비스(AITAG)의 개념 시연 |
| 타겟 사용자 | 웹 콘텐츠 제작자·기획자(대체텍스트를 써야 하는 사람), 접근성 담당자, AI 대체텍스트 서비스 도입을 검토하는 기업 담당자 |
| 사용자 가치 | 사진 한 장으로 30초 안에 초안 대체텍스트 + HTML 스니펫을 얻는다. 분야를 바꿔 보며 결과가 어떻게 달라지는지 비교할 수 있다 |
| 배포 | Vercel (URL 은 README) · 저장소 `Codyssey/AI_Application/mission3/aitag-demo` |

## 3. 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 사진 입력 | JPEG·PNG·WebP·GIF, 드래그 앤 드롭·클릭·Ctrl+V. 브라우저 Canvas 로 긴 변 1,600px·JPEG 로 축소해 전송(서버 저장 없음) |
| 프롬프트 매트릭스 | 분야 6 · 콘텐츠 유형 5 · 이미지 유형 6 · 카테고리 11 · 톤 3 (+ 길이 3 · 언어 2). 키 = `domain.content_type.image_kind.category.tone` |
| 블록 합성 | [공통 접근성 규칙] + [분야] + [콘텐츠 유형] + [이미지 유형] + [카테고리] + [톤] + [길이] + [언어] + [컨텍스트] + [출력 형식] |
| AI 생성 | Gemini `generateContent` 에 이미지 + 합성 프롬프트, JSON 스키마 강제 |
| 결과 표시 | 대체텍스트(복사 버튼) · HTML 스니펫 · 보충 설명 · 이미지 안 글 · 장식 여부 · 사용된 블록 칩 · 실제 프롬프트(펼치기) · 소요 시간·모델 |
| 샘플·프리셋 | 샘플 이미지 3종(포스터·식품 라벨·인포그래픽)이 매트릭스를 함께 맞춤, 매트릭스 페이지 예시 카드 → `?preset=` |
| 보너스 UX | 다크 모드(기기 설정 → 저장값) · Vercel Web Analytics |

## 4. AI 기능 설계 — 입력 / 출력 / 실패 처리

### 4-1. 입력

| 항목 | 규격 |
| --- | --- |
| 이미지 | base64(JPEG 로 축소), 4MB 이하, mime 4종 |
| 매트릭스 | 7축 키. 생략 시 기본값(`ecommerce.product.photo.general.plain`, standard, ko). 목록 밖 값은 기본값 대체 + `replaced` 표시 |
| 컨텍스트 | 선택, 500자. 제목·캡션 — "참고만, 이미지에 없는 내용 단정 금지" 규칙과 함께 전달 |

### 4-2. 출력 (JSON)

| 필드 | 내용 |
| --- | --- |
| `alt_text` | 대체텍스트(길이 옵션: 80/150자, 상세는 핵심 150자) |
| `long_description` | 보충 설명(불필요하면 빈 문자열) |
| `detected_text` | 이미지 안에 적힌 글 전문(없으면 빈 문자열) |
| `is_decorative` | 장식 이미지 판정(true 면 `alt=""` 안내) |
| `matrix_key` `blocks` `prompt` `model` `elapsed_ms` `replaced` | 투명성 — 무엇이 합성됐는지 그대로 보여 줌 |

### 4-3. 실패 처리 기준

| 상황 | 판정 | 사용자 안내 |
| --- | --- | --- |
| 빈 입력 | 사진 없음(프론트) / `EMPTY_IMAGE` 400(서버) | "사진을 올려 주세요. 대체텍스트를 만들 이미지가 없습니다." |
| 형식·크기 | `BAD_MIME` 400 · `IMAGE_TOO_LARGE` 413 · `BAD_IMAGE` 400 | 지원 형식·4MB 안내, 다른 파일로 재시도 |
| API 오류 | Gemini 4xx/5xx → `UPSTREAM_ERROR` 502 · 파싱 실패 `UPSTREAM_PARSE` 502 · 키 미설정 `NO_API_KEY` 500 | 메시지 + "잠시 후 다시 시도" · 코드 표시 |
| 한도 | 429 `RATE_LIMITED` | "지금 요청이 많습니다. 1분 뒤 다시 시도해 주세요." |
| 지연 | 서버 25초 `UPSTREAM_TIMEOUT` 504 · 브라우저 30초 abort | "응답이 30초 안에 오지 않았습니다…" |
| 선택지 로드 실패 | `/api/options` 실패 | "매트릭스 선택지를 불러오지 못했습니다. 새로고침해 주세요." |

- 원칙: 모든 오류는 JSON `{error, message}` 로 돌아오고 화면 `role="alert"` 영역에 표시된다. 생성 중에는 버튼 비활성 + 스피너 + `aria-live` 상태 문구

## 5. 테스트 시나리오

| 입력 | 기대 |
| --- | --- |
| 샘플 "행사 포스터" + `public.notice.poster.event.formal` | 행사명·일시·장소·대상·문의처가 격식체로, `detected_text` 에 포스터 문구 전문 |
| 샘플 "식품 라벨" + `ecommerce.product.product_detail_image.food.plain` | 제품명·용량·원재료·알레르기 표시 원문 보존 |
| 사진 없이 생성 | "사진을 올려 주세요" 안내, 요청 미발송 |
| Vercel 환경 변수 없이 배포 | 500 `NO_API_KEY` 안내 |
| 분당 한도 초과 | 429 안내 |

## 6. 비기능

- 개인정보: 이미지·결과를 저장하지 않음(로그에도 이미지 미기록). 서드파티는 Gemini 1곳
- 비용: Gemini 무료 티어. 공개 URL 이므로 한도 초과 시 429 안내로 흡수(추가 과금 없음)
- 접근성: 시맨틱 마크업, 건너뛰기 링크, 키보드로 업로드·샘플·카드 조작, `aria-live`, 대비 확보한 토큰, `prefers-reduced-motion`
