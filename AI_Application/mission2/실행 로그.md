# 실행 로그

- 국내 여행 추천 프로그램(travel-planner)의 개발 환경 · 실행 결과 · 오류 경로 · 요구사항 대조 기록
- 코드 위치: `travel-planner/` (Codyssey 저장소 안) · 결과물: `travel-planner/results/`
- 표기: **실호출** = 실제 Gemini·Kakao API 호출 · **오프라인 재현** = 같은 코드에 `requests` 만 가짜 응답으로 바꿔 실행(키·네트워크 불필요)

---

## 1. 개발 환경 확인

```text
$ python3 --version
Python 3.13.5

$ python3 -m pip install -r requirements.txt
requests 2.32.3 · python-dotenv 1.1.0        (테스트용 pytest 8.3.4)

$ cp -n .env.example .env        # GEMINI_API_KEY · KAKAO_REST_API_KEY 채움 (값은 기록하지 않음)
```

| 항목 | 확인 |
| --- | --- |
| Python 3.10 이상 | 3.13.5 |
| 외부 라이브러리 | `requests`(HTTP) · `python-dotenv`(.env) — SDK 미사용 |
| LLM | Google Gemini `gemini-3.5-flash-lite` 무료 티어 (REST `generateContent` **POST**) |
| 지도/장소 | Kakao Local 키워드 검색 (REST `keyword.json` **GET**) · Naver 지역 검색은 교체용(오프라인 테스트로만 확인) |
| 키 관리 | `.env` (git 제외) 또는 환경변수. 코드·README·결과물에 키 없음 |

- Kakao 키 설정 중 실측한 오류 2가지 — README 에 반영
  · JavaScript 키를 쓰면 `401 KA Header is required but neither os nor origin field is given` → **REST API 키**여야 함
  · 앱 설정 → 카카오맵 활성화가 꺼져 있으면 `403 App(...) disabled OPEN_MAP_AND_LOCAL service.` → **활성화 ON**
- `.env` 를 `cp .env.example .env` 로 다시 만들면 채운 값이 템플릿으로 덮어써짐(실제로 겪음) → 안내를 `cp -n` 으로 바꾸고, 키가 빈 원인을 구분해 안내하도록 수정

  → 셸 환경변수가 빈 값이라 .env 의 값을 가립니다. 해제: unset GEMINI_API_KEY

- `2026-1-5` 는 `strptime` 이 받아 주지만 파일명·캐시 키가 `2026-01-05` 와 갈리므로 거부

## 3. 정상 실행 — 복수 지역 3곳 (실호출 · 2026-10-06 23:59)

```text
$ python3 travel_planner.py -date "2027-03-15"
[1/3] 1차 추천 생성 중(LLM · gemini-3.5-flash-lite)...
    - recommended_city: "제주"
    - recommended_city: "강릉"
    - recommended_city: "경주"
[2/3] 맛집 검색 중(Kakao Local)...
    - 제주: 맛집 5곳 검색 완료
    - 강릉: 맛집 5곳 검색 완료
    - 경주: 맛집 5곳 검색 완료
[3/3] 최종 리포트 생성 중(LLM)...
    - 리포트 생성 완료

완료! results/2027-03-15_travel_plan.md 를 확인하세요.
      원본 데이터: results/2027-03-15_raw.json
(약 9초 · Gemini 2회 · Kakao 3회)
```

- `results/2027-03-15_raw.json` — 1차 추천 JSON(파싱 결과). LLM 응답 최상위에 필수 4키가 그대로 있고, 보너스 `other_cities` 를 합친 `recommended_cities` 가 붙음

```json
{
  "recommended_city": "제주",
  "weather": "3월 중순의 제주는 포근하며 완연한 봄기운을 느낄 수 있으나, ...",
  "events": ["제주들불축제", "유채꽃 및 매화 축제"],
  "reason": "3월 중순의 제주는 노란 유채꽃과 붉은 매화가 섬 전체를 물들여 ...",
  "recommended_cities": [ {"recommended_city": "제주", ...}, {"recommended_city": "강릉", ...}, {"recommended_city": "경주", ...} ]
}
```

- 그 밖의 필드: `options: {"cities": 3, "count": 5}` · `place_provider: "kakao_local_keyword"` · `places` 지역별 5곳(`name address category url x y phone`) · `errors: []`
- `results/2027-03-15_travel_plan.md` — `추천 지역` 요약 → 지역별 `추천 이유 · 날씨 요약 · 행사/축제 · 맛집 추천(5곳, 링크) · 1일 일정 제안(오전/오후/저녁, 맛집을 식사 시간에 배치)` → `오류 요약(errors): 없음`. 리포트 필수 항목 검사 통과(대체 리포트 아님)

    - 강릉: 5곳
    - 경상북도: 5곳
[3/3] 최종 리포트 생성 중(LLM)...

- 2회째는 Gemini 1회(리포트)만 호출 — 1차 추천 1회 + Kakao 3회 절약. 2026-09-13 실호출에서도 같은 동작 확인
- 캐시를 **쓰지 않는** 경우 — 실패를 캐시로 굳히지 않기 위해

```text
[캐시] results/2026-12-24_raw.json 를 쓰지 않습니다 — 이전 실행에 맛집 검색 오류(AUTH_ERROR) 기록. API 를 다시 호출합니다
```

| 조건 | 이유 |
| --- | --- |
| 1차 추천 실패 기록 | 다음 단계 입력이 없음 |
| 맛집 검색 오류(인증·쿼터·네트워크) 기록 | 키를 고치거나 한도가 풀린 뒤에는 새로 검색해야 함 (0건은 재사용) |

| 파일이 깨짐 | 읽기 실패 안내 후 다시 호출 |

## 5. 지도 API 인증 실패 — 잘못된 Kakao 키

- 실호출(2026-09-13, `--cities 1`) — 제출 샘플 `results/2026-12-24_*`

```text
$ KAKAO_REST_API_KEY=wrongkey python3 travel_planner.py -date "2026-12-24" --cities 1
[2/3] 맛집 검색 중(Kakao Local)...
  - 오류: 인증 실패(401). 키 설정을 확인하세요.
  - 맛집 섹션은 '데이터 없음'으로 처리하고 계속 진행합니다.
[3/3] 최종 리포트 생성 중(LLM)...
    - 리포트 생성 완료
```

- 현재 출력(오프라인 재현, 3지역) — 지역명 표시 · 같은 키로 나머지 지역 호출 생략 · 오류 유형별 조치 안내

```text
[2/3] 맛집 검색 중(Kakao Local)...
    - 제주: 오류: 인증 실패(401). 키 설정을 확인하세요.
    - 제주: 맛집 섹션은 '데이터 없음'으로 처리하고 계속 진행합니다.
    - 강릉: 앞 지역에서 AUTH_ERROR — 같은 키라 검색을 건너뜁니다 (데이터 없음)
    - 경주: 앞 지역에서 AUTH_ERROR — 같은 키라 검색을 건너뜁니다 (데이터 없음)
[3/3] 최종 리포트 생성 중(LLM)...
    - 리포트 생성 완료

완료! results/2026-12-24_travel_plan.md 를 확인하세요.
      원본 데이터: results/2026-12-24_raw.json
      오류 3건 — 리포트 끝 '오류 요약(errors)' 참고
        · place_search AUTH_ERROR: HTTP 401 (query=제주 맛집)
          → 키 값·권한을 확인하세요 (Kakao: REST API 키·카카오맵 활성화 / Naver: Client ID·Secret·검색 API 사용 설정 / Gemini: AI Studio 키)
        · place_search AUTH_ERROR: 앞 지역의 AUTH_ERROR 로 검색 생략 (query=강릉 맛집)

```

- 리포트 `### 맛집 추천` → `- 데이터 없음 (장소 검색 결과 0건)`, 끝에 `## 오류 요약(errors)`
- 원본 JSON → `"errors": [{"step": "place_search", "type": "AUTH_ERROR", "message": "HTTP 401 (query=제주 맛집)"}, ...]`

## 6. 그 밖의 오류 경로 (오프라인 재현)

- 1차 추천 JSON 이 깨진 경우 — 닫는 괄호 없는 응답 → 실패 이유를 넣은 프롬프트로 **1회만** 재요청 → 복구, 첫 실패도 `errors` 에 남김

```text
[1/3] 1차 추천 생성 중(LLM · gemini-3.5-flash-lite)...
    - JSON 파싱 실패(시도 1: Expecting ',' delimiter: line 1 column 61 (char 60)) → 필수 키만 다시 요청
    - recommended_city: "제주"
...
        · recommend PARSE_ERROR: 시도 1: Expecting ',' delimiter: ... → 필수 키만 다시 요청(재시도 1회)
          → LLM 응답 형식 문제입니다 — 다시 실행하면 대개 해결됩니다
```

- 맛집 0건 — 중단 없이 다음 단계로, 리포트에 `데이터 없음` + 지도에서 직접 찾기 링크

```text
[2/3] 맛집 검색 중(Kakao Local)...
    - 제주: 맛집 5곳 검색 완료
    - 강릉: 검색 결과 0건(키워드를 바꿔 재시도하지 않고 다음 단계로 진행)
...
        · place_search EMPTY_RESULT: 0 results for query=강릉 맛집
          → 검색 결과가 없습니다 — 리포트의 '직접 찾기' 링크로 지도에서 찾아보세요
```

- 리포트 LLM 이 503 을 두 번 돌려준 경우 — 1회 재시도 후 데이터만으로 대체 리포트

```text
[3/3] 최종 리포트 생성 중(LLM)...
    - 일시 오류(HTTP 503) — 1.5초 뒤 1회 재시도
    - 오류: HTTP_ERROR — HTTP 503 overloaded
    - 데이터만으로 대체 리포트를 생성합니다
```

- 넓은 지역명 — LLM 이 도 단위(`경상북도`)를 주면 검색어를 대표 도시로 보정해 검색 (리포트의 지역명은 그대로)

```text
[2/3] 맛집 검색 중(Kakao Local)...
    - 경상북도: 검색어 보정: '경상북도' → '경주 맛집'
    - 경상북도: 맛집 5곳 검색 완료
```

## 8. (추가) 웹 화면 — 로컬 서버

```text
$ python3 web.py
여행 추천 웹 화면: http://localhost:8000   (종료: Ctrl+C)
  지도: 카카오 지도 (카카오 콘솔 → 플랫폼 → Web 에 http://localhost:8000 등록 필요, 실패 시 OpenStreetMap)
```

- 실서버 조회(API 호출 없음) — `GET /api/results` 4건(2027-03-15 · 2026-12-24 · 2026-11-07 · 2026-10-03), 상세 조회 시 예전 형식 파일도 현재 형식으로 읽힘, `2026-12-24` 오류에 조치 안내 포함
- 생성 경로(오프라인 재현) — `POST /api/plan` 이 `step`·`log` 이벤트를 한 줄씩 보낸 뒤 마지막 줄에 결과(`ok` · `saved` · `errors` + 조치 안내 · `markdown`)
- 잘못된 날짜 → `400 {"error": "날짜 형식이 올바르지 않습니다: ...", "field": "date"}` · `/static/../config.py` → 404
- 브라우저 점검(2026-10-07, 크롬 · 저장된 결과만 조회 · API 호출 0건)

| 점검 | 결과 |
| --- | --- |
| 첫 화면 | 날짜 기본값(오늘+7일) · 3곳 · 5곳 · 저장된 결과 4건(`2026-12-24` 에 오류 배지) |
| 결과 보기 | 리포트 HTML 렌더(Markdown 기호 노출 없음) · 머리말 메타(지역 · 생성 시각 · 모델) |
| 지도 | 카카오 SDK 로드 실패 → **OpenStreetMap 자동 대체**(`OpenStreetMap (카카오 지도 실패 → 대체)`) · 핀 15개 지역별 색 · 지역 필터 · 목록 "지도" 버튼 → 팝업·강조 |
| 오류 안내 | `2026-12-24` → `AUTH_ERROR` 카드 + 조치 안내 · 맛집 `데이터 없음` · 지도는 핀 없이 표시 |
| 입력 검증 | 날짜 비움 · 맛집 수 99 → 칸 아래 안내, 요청 0건 |
| 좁은 화면(390px) | 한 열로 쌓임 · 가로 스크롤 없음 |
| 콘솔 · 키 | error 0건(warning = 카카오→OSM 대체 안내 1건) · 화면·응답에 서버 키 없음 |

- 카카오맵은 카카오 콘솔에 `http://localhost:8000` 을 등록해야 표시됨 — 미등록 상태라 OSM 으로 표시(기능 영향 없음)
