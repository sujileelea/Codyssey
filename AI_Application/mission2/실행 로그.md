# 실행 로그

- 국내 여행 추천 프로그램(travel-planner)의 개발 환경 확인 · 실행 결과 · 요구사항 대조 기록 (2026-09-13)
- 코드 위치: `travel-planner/` (Codyssey 저장소 안) · 결과물: `travel-planner/results/`

---

## 1. 개발 환경 확인

```text
$ python3 --version
Python 3.13.5

$ python3 -m pip install -r requirements.txt
requests 2.32.3 · python-dotenv 1.1.0

$ cp .env.example .env        # GEMINI_API_KEY · KAKAO_REST_API_KEY 채움 (값은 기록하지 않음)
```

| 항목 | 확인 |
| --- | --- |
| Python 3.10 이상 | 3.13.5 |
| 외부 라이브러리 | `requests`(HTTP) · `python-dotenv`(.env) — SDK 미사용 |
| LLM | Google Gemini `gemini-3.5-flash-lite` 무료 티어 (REST `generateContent` **POST**) |
| 지도/장소 | Kakao Local 키워드 검색 (REST `keyword.json` **GET**) |
| 키 관리 | `.env` (git 제외) 또는 환경변수. 코드·README·결과물에 키 없음 |

- Kakao 키 설정 중 실측한 오류 2가지 — README 에 반영
  · JavaScript 키를 쓰면 `401 KA Header is required but neither os nor origin field is given` → **REST API 키**여야 함
  · 앱 설정 → 카카오맵 활성화가 꺼져 있으면 `403 App(...) disabled OPEN_MAP_AND_LOCAL service.` → **활성화 ON**

```text

(exit 2)

$ python3 travel_planner.py -date 2026-10-03        # .env 없이
API 키가 설정되지 않았습니다: GEMINI_API_KEY, KAKAO_REST_API_KEY

설정 방법 (둘 중 하나):
  1) .env 파일 — .../travel-planner/.env
       cp .env.example .env   후 값 채우기
       GEMINI_API_KEY=...        # https://aistudio.google.com/ → Get API key
       KAKAO_REST_API_KEY=...    # https://developers.kakao.com/ → 내 애플리케이션 → 앱 키 → REST API 키
                                 #   (앱 설정 → 카카오맵 → 활성화 설정 ON 필요)
  2) 환경변수 (현재 터미널 세션에만 적용)
       macOS/Linux:  export GEMINI_API_KEY="YOUR_KEY"
       PowerShell:   $env:GEMINI_API_KEY="YOUR_KEY"
(exit 1)
```

```text
    - recommended_city: "강릉"

    - 제주: 맛집 5곳 검색 완료
    - 경주: 맛집 5곳 검색 완료
    - 강릉: 맛집 5곳 검색 완료

```

- `results/2026-10-03_raw.json` — 1차 추천 JSON(파싱 결과)

```json
{
  "recommended_city": "제주",
  "weather": "10월 초의 제주는 쾌청하고 선선한 가을 날씨를 보여 야외 활동을 하기에 가장 이상적입니다.",
  "events": ["탐라문화제", "제주들꽃축제"],
  "reason": "개천절 연휴를 맞아 천혜의 자연경관과 푸른 바다를 만끽하기에 더없이 좋은 시기입니다. ...",
  "recommended_cities": [ {"city": "제주", ...}, {"city": "경주", ...}, {"city": "강릉", ...} ]

```

- 맛집 검색 결과 1건 (지역별 5건 × 3지역)

```json
{"name": "맛나식당", "address": "제주특별자치도 서귀포시 성산읍 동류암로 41",
```

- `results/2026-10-03_travel_plan.md` — 지역별 `추천 이유 · 날씨 요약 · 행사/축제 · 맛집 추천(5곳, 주소·카테고리·링크) · 1일 일정 제안(오전/오후/저녁, 맛집을 식사 시간에 배치)` + `오류 요약(errors): 없음`

## 5. 지도 API 인증 실패 — 잘못된 Kakao 키

```text
$ KAKAO_REST_API_KEY=wrongkey python3 travel_planner.py -date "2026-12-24" --cities 1
[1/3] 1차 추천 생성 중(LLM · gemini-3.5-flash-lite)...
    - recommended_city: "제주"
[2/3] 맛집 검색 중(Kakao Local)...
  - 오류: 인증 실패(401). 키 설정을 확인하세요.
  - 맛집 섹션은 '데이터 없음'으로 처리하고 계속 진행합니다.
[3/3] 최종 리포트 생성 중(LLM)...
    - 리포트 생성 완료

완료! results/2026-12-24_travel_plan.md 를 확인하세요.
      원본 데이터: results/2026-12-24_raw.json
      오류 1건 — 리포트 끝 '오류 요약(errors)' 참고
```

- 리포트 `### 맛집 추천` → `- 데이터 없음 (장소 검색 결과 0건)`, `## 오류 요약(errors)` → `` `place_search` · `AUTH_ERROR` — HTTP 401 (query=제주 맛집) ``
- `results/2026-12-24_raw.json` → `"errors": [{"step": "place_search", "type": "AUTH_ERROR", "message": "HTTP 401 (query=제주 맛집)"}]`
- 이 샘플은 오류 경로 시연용으로 **일부러 틀린 키**로 만든 것. `results/` 에 그대로 둠

## 7. 요구사항 대조

| 요구 | 충족 |
| --- | --- |
| argparse · `-date` 필수 · 형식 오류 시 사용법 출력 후 종료 | `build_parser()` `valid_date()` — §2 |
| LLM 택1 · 지도 택1 | Gemini · Kakao Local |
| 1차 JSON 스키마 `recommended_city` `weather` `events[]` `reason` | `llm_api.recommend()` — JSON 모드 + `responseSchema` + 키·타입 검사 |
| 맛집 N곳(5) · `name address category url x y` | `place_api.search_restaurants()` — §3 |
| 검색 0건·실패 시 중단 없이 "데이터 없음" 진행 | §5 · 테스트 |
| 최종 리포트 항목(추천 지역·이유·날씨·행사·맛집·1일 일정) | `results/*_travel_plan.md` |
| try-except · 키 미설정 즉시 종료 · 지도 실패 계속 · LLM 파싱 재시도 1회 · errors 목록 | `config.require_keys()` `errors.ErrorLog` · 재시도 `for attempt in (1, 2)` |
| 키 코드 미기재 · .env/환경변수 · 제출물에 키 없음 | `.env` git 제외, `.env.example` 만 커밋 |
| `results/` 원본 JSON(추천+맛집+errors) · 리포트 md | `report.py` — 날짜 기준 파일명 |
| README(개요·실행·키 설정·결과 확인·유출 주의) | `travel-planner/README.md` |
| 보너스 — 복수 지역 · 캐싱 | `--cities 3` 기본 · 원본 JSON 캐시 + `--no-cache` |
