국내 여행 추천

날짜를 고르면 LLM이 지역을 추천하고, 지도 API로 맛집을 찾아 여행 리포트를 만듭니다.

여행 조건

추천은 그 시기의 일반적인 날씨·행사를 기준으로 합니다

추천 지역 수

1~15곳

저장된 결과

API 호출 없이 다시 봅니다

    이렇게 동작합니다

    1. 1
      지역 추천

      Gemini가 그 날짜에 여행하기 좋은 지역과 날씨·행사를 JSON으로 답합니다

    2. 2
      맛집 검색

      추천 지역마다 Kakao Local로 맛집을 찾습니다 — 실패해도 멈추지 않습니다

    3. 3
      여행 리포트

      Gemini가 추천·맛집을 묶어 1일 일정이 담긴 리포트를 씁니다

    결과는 results/ 폴더에 원본 JSON과 Markdown 리포트로 저장됩니다.

    진행 상황

    1. 지역 추천LLM 대기
    2. 맛집 검색지도 API 대기
    3. 리포트 작성LLM 대기
